# Saad Gul — Portfolio Website

> **Front-End Engineer & Shopify Specialist** (5+ Years Experience)  
> Custom Shopify Themes (OS 2.0 / Liquid) • Modern Web Apps (React / Next.js) • Performance & CRO

A high-performance, responsive portfolio website built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**. Designed with a deep obsidian pitch-black theme (`#030305`), interactive physics-based card tilts, animated edge glow tracers, and full SEO/JSON-LD schema markup.

---

## ⚡ Tech Stack

- **Framework:** Next.js (App Router & Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Animations:** CSS Keyframe Perimeters & 3D Pointer Glare
- **Typography:** Geist & Geist Mono
- **SEO:** Metadata API, OpenGraph, JSON-LD Schema (Person & WebSite), Sitemap & Robots.txt

## 🚀 Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production

```bash
npm run build
npm run start
```
